Interactive Branch & Commit Graph

Understand your project's history at a glance without visual chaos. Pragma-git structures complex repository histories with clear, distinct swimlanes rather than tangled spaghetti lines:

  • ✓ Clean Swimlanes: Dedicated parallel branch lanes keep your merge paths and feature branches cleanly separated and easy to follow.
  • ✓ Commit Pinning: Pin any reference commit to compare and measure changes directly against your current working state.
  • ✓ Instant Commit Details: Click any commit node to inspect author, hash, commit message, and changed files.
  • ✓ Fast History Stepping: Quickly review consecutive revisions using up and down arrow keys.

Visual Help for Merge Clashes & Diffs

Merge conflicts are one of the biggest pain points in Git. Pragma-git includes Pragma-merge to walk you through conflict resolution with visual confidence:

  • ✓ 2-way and 3-way views: Compare side-by-side or use a 3-pane view with local, incoming, and merged result editor.
  • ✓ Single-click chunk adoption: Interactive arrows let you accept the incoming version or keep yours with a single click.
  • ✓ Line ending & permission safe: Automatically normalizes Windows CRLF vs POSIX LF differences and preserves executable flags.
  • ✓ 70+ syntax modes: High-contrast syntax highlighting for every major programming language.
  • ✓ Bring your own tool: If you already have a favorite external diff or merge tool configured (e.g. Beyond Compare, Meld, VS Code), Pragma-git supports it seamlessly.

Full Note-Taking App Inside Your Repo

Never lose track of your work in progress. Pragma-git includes a complete Markdown & WYSIWYG note-taking environment tied directly to each repository:

  • ✓ Rich Formatting: Headings, interactive checkboxes, tables, and highlighted code snippets.
  • ✓ Repository-Specific: Each project maintains its own dedicated notes file right where your code lives.
  • ✓ Dual Mode: Switch effortlessly between formatted visual editing and raw Markdown.

Self-Explaining UI & Interactive Guide
